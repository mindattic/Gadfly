# Understanding Multiplication

These notes support the demonstration assessment on multiplication (docs/MASTER-PLAN.md Part 2.2). They are
written for teachers of upper-primary students and cover what it means to understand multiplication, not only
how to recall multiplication facts.

## Multiplication as equal groups

Multiplication combines equal groups. Three bags with four apples in each bag hold three groups of four
apples, which is twelve apples in total. The product counts everything in all of the groups together.

Multiplication is closely related to addition: three groups of four can be found by repeated addition, four
plus four plus four. Multiplication is a faster way to add the same number many times, and the repeated
addition only works because every group has the same size.

When the groups are not equal, multiplication does not describe the total. Two bags with three apples and one
bag with five apples cannot be written as a single multiplication of whole numbers; the student has to add.

### Common misconceptions

- Multiplication is just a list of facts to memorise, with no meaning behind it.
- Any collection of groups can be multiplied, even when the groups have different sizes.

## What each factor represents

In an equal-groups multiplication, one factor is the number of groups and the other factor is the size of
each group. In three bags of four apples, the three is the number of bags and the four is the number of
apples in each bag. The two numbers describe different things even though the product is the same either way.

Because multiplication is commutative, three groups of four and four groups of three both make twelve, but
the situations are different: three bags of four apples is not the same arrangement as four bags of three
apples. Understanding the roles of the factors means being able to say what each number stands for in a story.

### Common misconceptions

- The order of the factors never matters for what the numbers mean in a situation.
- The bigger number is always the number of groups.

## How changing a factor changes the product

If the number of groups doubles while the size of each group stays the same, the total doubles: six bags of
four apples hold twenty-four apples, twice as many as three bags. The product changes in proportion to each
factor, because every new group adds the same amount again.

The same reasoning works for any factor: tripling the size of each group triples the total, and halving the
number of groups halves the total. This is the start of seeing multiplication as scaling, where one quantity
is stretched or shrunk by a factor.

Multiplication as scaling goes beyond equal groups. Multiplying by a fraction smaller than one, such as one
half, makes a quantity smaller, so multiplication does not always make numbers bigger.

### Common misconceptions

- Multiplication always makes a number bigger.
- Doubling the number of groups adds two more apples to the total.
