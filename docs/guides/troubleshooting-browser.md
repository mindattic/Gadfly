# Browser and connection problems

## Which browsers work

Use a **current version** of Chrome, Edge, Firefox or Safari. The table shows where each one is available:

| Browser | Windows | Mac | Chromebook | Linux | iPhone / iPad | Android |
|---|---|---|---|---|---|---|
| Chrome | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| Edge | ✓ | ✓ | | | | |
| Firefox | ✓ | ✓ | | ✓ | | |
| Safari | | ✓ | | | ✓ | |

Gadfly doesn't check the browser's name; the get-ready page checks what the browser can actually do (a live
connection, cookies, the microphone and camera on a secure page), so **its system check is what counts**: if every
check passes, your browser works. Other browsers built on Chrome (Brave, Opera, Vivaldi) often pass too, but aren't
tested. A computer or a tablet gives the examiner and
your camera more room than a phone; a window narrower than 360 pixels is flagged as a warning.

Keep your browser up to date: open its **About** page (Chrome: `chrome://settings/help`, Edge:
`edge://settings/help`, Firefox: **Help > About Firefox**) and it updates itself. On iPhone, iPad and Mac, Safari
updates with the system.

## The get-ready checks

| Check | If it fails |
|---|---|
| **Browser**: "this browser can't keep a live connection" | Use a current Chrome, Edge, Firefox or Safari. A company or school network that blocks WebSockets can also cause it: try another network. |
| **Cookies**: "blocked" | Allow cookies for this site in your browser's settings, then reload. Private or incognito windows with strict settings can block them. |
| **Connection**: "slow" (a warning) | You can carry on, but the examiner may be slow to respond. Move closer to the Wi-Fi router or stop other downloads. |
| **Connection**: "too slow" or "offline" | Move closer to the router, use a cable, stop other streams and downloads, or reconnect, then **Check again**. |
| **Screen**: "very narrow" (a warning) | Make the window wider, or use a tablet or computer. |
| **Spoken examiner**: "not turned on for this site" | Only your organization can fix this. Tell your instructor; you can't take the exam until it is on. |
| "the check couldn't run" / "the connection to the server was lost" / "no response from your browser" | Press **Check again**. If it keeps happening, reload the page. |

## The examiner is silent

- **Press "Continue to the examiner"** if you see **One click to go**: browsers need a click before a page may
  play sound.
- Check the **volume**, the right **speaker or headphones** in your system's sound settings, and that the browser
  tab isn't muted (right-click the tab).
- The question is always shown as text too, and **Repeat the question** plays it again.

## The examiner shows a glowing sphere instead of a moving head

Your browser has no 3D graphics available, the device can't draw her smoothly, or her 3D head couldn't load. The exam
works the same: the sphere glows as she speaks, and the questions are still spoken and shown as text. (Reduced motion
doesn't cause this: she stays live, just with gentler movement.) Turning on hardware acceleration in the browser's settings may bring
the moving head back.

## The page stops responding, or the connection drops

- **Don't panic: your progress is saved after every answer**, and the time is kept on the server.
- If the exam shows **The exam is paused** because the connection to the examiner was lost, check your internet
  connection and press **Try again**.
- If the page is frozen, **reload** it. Sign in again if asked, open **My exams** and press **Resume**: you return to
  the same question.
- The clock keeps running while the page is closed. It only stops during a pause shown by the exam itself (a lost
  microphone, camera or examiner connection), for up to 10 minutes in all.

## Extensions, VPNs and networks

- Ad blockers and privacy extensions can block the live connection, the speech service or the camera. If
  something fails, try a private window with extensions off, or allow this site in the extension.
- A VPN or a strict firewall can block live connections. Try without it, if your organization allows.
- On a shared network (a library, a café), the connection may be slow or block live connections. A phone hotspot
  is a good fallback.

## A good set-up, in short

A current Chrome or Edge on a laptop or desktop, a wired headset with a microphone, a steady connection, and every
other call app closed. See [Before your exam](before-your-exam.md).
