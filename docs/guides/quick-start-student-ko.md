# 학생 빠른 시작(한국어)

초대받은 뒤 시험을 제출하기까지 다섯 단계예요. 화면 위쪽의 언어 선택에서 **한국어**를 고르면 학생 화면이 한국어로 바뀌고,
시험 준비 페이지에서 시험을 한국어로 볼지 고를 수 있어요(시험이 한국어를 제공하는 경우).

1. **로그인하기.** 초대 이메일의 링크로 비밀번호를 정하거나, 담당 교수자가 알려 준 사용자 이름과 임시 비밀번호로
   로그인해요(처음 로그인할 때 새 비밀번호를 정해요).
2. **내 시험 열기.** 배정된 시험이 응시 기간, 응시 횟수와 함께 나와요(시험이 배정되면 이메일이 올 수도 있어요).
3. **시작을 누르고 시험 준비하기.** 시험 준비 페이지 하나에서 모든 준비를 해요([시험 준비와 언어](get-ready-and-languages-ko.md)).
   - **사용 언어:** 할 수 있는 언어와 가장 잘하는 언어를 알려 주세요. 채점에는 절대 쓰이지 않아요.
     그리고 이 시험을 볼 언어를 골라요. 고르는 즉시 페이지와 안내, 시험관이 그 언어로 바뀌어요.
     **시험 시작**을 누르면 이번 응시 동안 그 언어로 고정돼요.
   - **카메라와 마이크:** 사용할 장치를 고르고 허용해요. 몇 마디 말해서 막대가 움직이고 모든 항목이 ✓가 될 때까지 기다려요.
   - **목소리 맞추기(선택):** 짧은 문장을 세 번 읽으면 음성 인식이 말하는 속도에 맞춰져요. 숫자 몇 개만 저장되고 녹음은 저장되지 않아요.
   - **시험관 만나기:** 시험관을 고르고 인사를 들어 봐요.
   - 안내를 읽고 동의에 체크한 뒤 **시험 시작**을 눌러요. 시험 시작을 누르기 전에는 아무것도 기록되지 않고 응시 횟수도 쓰이지 않아요.
4. **시험관과 이야기하기.** 시험관이 한 번에 하나씩 소리 내어 질문해요. 자신의 말로 소리 내어 답해요.
   말을 멈추면 잠시 뒤 답이 들은 그대로 제출돼요. 다시 읽어 주거나 다시 할 기회는 없으니, 제출되기 전에 하고 싶은 말을 해 주세요.
   "잘 모르겠어요"도 솔직한 답이에요. 질문이 잘 이해되지 않으면 **질문 다시 듣기**나 **다른 말로 다시 묻기**를 누르세요.
   시험관이 같은 질문을 다른 말로 다시 물어봐요. 언제든 쓸 수 있고, 점수에는 영향을 주지 않아요.
5. **결과 기다리기.** 답변은 사람이 채점해요. 결과가 공개되면 **내 시험**에 전체 보고서와 함께 나타나고, 이의 신청을 할 수 있어요.

## 시선 맞추기

- 시험관이 질문할 때와 답할 때는 화상 통화를 하듯 시험관을 봐 주세요.
- **생각하느라 시선을 돌리는 것은 아주 자연스러운 일이에요.** 화면을 뚫어지게 볼 필요는 없어요.
- 답하는 동안 화면에서 오래 눈을 떼고 있을 때만 부드러운 알림이 나와요. 알림은 성적에 전혀 영향을 주지 않으며, 시험이 자동으로 끝나는 일도 없어요.
- 카메라는 자리에 있는지, 혼자 있는지, 화면을 보고 있는지만 이 기기 안에서 확인해요. 영상은 기록되거나 전송되지 않으며, 카메라는 채점하거나 무언가를 결정하지 않아요.
- 시험 중에는 자신의 모습이 보이지 않고, 작은 카메라 켜짐 표시만 나와요. 자세한 내용은 [시선 맞추기와 부드러운 알림](eye-contact-ko.md)에 있어요.

## 시험 창을 벗어나면

- 다른 창이나 탭으로 옮기면 시험이 일시 정지되고, 하던 말은 그대로 남아요. 돌아오면 시험관이 질문 끝부분을 다시 말해 줘요.
- 여러 번 또는 오래 벗어나면 담당 교수자가 살펴보도록 표시되고, 무슨 일이 있었는지 적을 수 있어요. 시험이 자동으로 취소되는 일은 없어요. 자세한 내용은 [시험 창을 벗어나면](leaving-the-exam-window-ko.md)에 있어요.

## 시험 전에

- **내 시험**의 **시험관 만나기(연습)** 또는 시험 준비 페이지의 무료 연습 시험을 해 보세요. 5분이면 되고, 아무것도 저장되거나 집계되지 않아요.
- 헤드셋, 조용한 방, 얼굴 앞쪽의 조명을 준비하고, 다른 통화 앱은 닫아 주세요.
- 각 주제를 **소리 내어** 설명하는 연습을 해 보세요. *왜* 그런지까지요.
- 시간이 더 필요하거나, 시선을 맞추기 어렵거나, 소리 내어 답하기 어렵다면 지금 담당 교수자에게 편의 지원을 요청하세요.

## 문제가 생기면

- 시험 준비 페이지에 ✗가 보이면: 표시된 해결 방법을 따른 뒤 **다시 점검**을 눌러 주세요.
- 시험이 일시 정지되면: 안내된 문제를 해결하고 **다시 시도**를 눌러 주세요. 모두 합해 최대 10분까지 시간이 멈춰요.
- 화면이 멈추면: 페이지를 새로 고친 뒤 **내 시험**에서 **이어서 하기**를 눌러 주세요. 지금까지의 답은 저장되어 있어요.

자세한 내용은 영어로 된 [Student guide](STUDENT_GUIDE.md)에 있어요.
